# Supplementary Materials

This directory contains calculation records, figure inputs and code, source
structures, workflow scripts, molecular-dynamics animations, and the
supplementary table workbook.

| Section | Contents |
|---|---|
| `00_README_and_File_Maps` | Navigation maps for calculations, figures, and source structures. |
| `01_Calculations` | ORCA and MD input/output files, geometries, Amber topologies, trajectories, and trajectory analyses. |
| `02_Figure_Plotting_and_Data` | Main-text and supplementary plotting/rendering scripts with adjacent numeric CSV and structure inputs; PNG exports are under `figure_exports`. |
| `03_Calculation_Preparation_and_Workflow_Code` | Non-plotting model-building, validation, production and analysis scripts. |
| `04_Source_Structures_and_Model_Building` | Initial DFT structures and pVBTMA12 model/structure provenance. |
| `05_MD_Animations` | One production movie per pVBTMA12-PFOA replica, frame manifests and renderer. |
| `06_Table_Workbooks` | `Supplementary_Tables_S1-S11.xlsx` and companion workbook navigation. |

Source calculation stems such as `R4N` are retained verbatim. The navigation
maps distinguish minimal BTMA from extended DVB-BTMA calculations.
