# Figure 14 MD Structural Rendering

This folder contains the plotting code and representative structural inputs used
to render the Figure 14 MD structural panels.

## Scripts

- `render_figure14_raws.py`: renders the raw structural panels for the MD
  snapshots, the full-system representation, and the hydrated PFOA binding-site
  view.
- `assemble_figure14.py`: assembles the rendered panels into the multi-panel
  Figure 14 layout.
- `figure14_render_core.py`: shared rendering utilities used by
  `render_figure14_raws.py`.

Run `render_figure14_raws.py` first to generate the structural render outputs,
then run `assemble_figure14.py` to assemble the multi-panel figure layout and
create the no-label base image used by the label-adjustment GUI. Generated
images are written to an `outputs/` directory when the scripts are run and are
not included in this supplement.

## Input Data

- `input_data/pfoa_assoc_frame_*_resin_pfo_cl.pdb`: representative dry PFOA/R48
  association snapshots.
- `input_data/resin_pfoa_exchange_npt_1ns_final_imaged.pdb`: full imaged
  solvated endpoint structure.
- `input_data/r48_pfoa_47cl.prmtop` and
  `input_data/solvated_resin_pfoa_exchange.prmtop`: Amber topology files used
  to derive rendering connectivity.

## Labeling GUI

The `labeling_gui/` folder contains the HTML-based label adjustment interface
and the current label anchor JSON/JavaScript files. The GUI base PNG is
generated by `assemble_figure14.py` as
`labeling_gui/Figure_14_label_dragger_base.png`; it is intentionally not
included as a premade image. After generating the base PNG, open
`labeling_gui/Figure_14_label_dragger.html` in a browser to move labels and
export an updated PNG or JSON layout.
