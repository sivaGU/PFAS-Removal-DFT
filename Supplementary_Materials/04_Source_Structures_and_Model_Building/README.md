# Source Structures and Model Building

`01_initial_small_molecule_structures` contains downloaded and prepared DFT
starting structures. `02_pVBTMA12_current_model` contains the stereo-defined
graph, UFF-minimized 3D structure, validation records, RCT
charge-source/transfer models, dry and solvated structures, and the prepared
PFOA-associated construction. The corresponding full AMBER build inputs,
topologies and logs are under `../01_Calculations/05_MD/01_Validation_and_Associated_Pilot`.

Figure 14's selected production frame is documented in its plotting folder.
